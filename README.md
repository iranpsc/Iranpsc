# Paradise Supply Chain Holding (`IranPSC`)

**Engineering the Digital Infrastructure, Distributed Systems, and Virtual Economy of the [Paradise Supply Chain](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc) & [MetaRang](https://www.google.com/search?q=https%3A%2F%2Fmetarang.com) Ecosystem.**

## Core Ecosystem Pillars

### 1. [MetaRang](https://www.google.com/search?q=https%3A%2F%2Fmetarang.com) — Intelligent 3D Parallel World

**[MetaRang](https://www.google.com/search?q=https%3A%2F%2Fmetarang.com)** is an interactive, persistent 3D parallel world that converges spatial computing, artificial intelligence, virtual real estate (**VOD**), digital academies, and decentralized governance:

* **High-Performance Web Portals:** Built with modular **Next.js (`TypeScript`)** and **React.js**, featuring a unified multi-theme Design System, SSR caching proxies, global Skeleton loading states, `GLTF` 3D model inspection, and real-time **Sentry** telemetry.
* **Event-Driven UI Studio (`UGC`):** Decouples visual presentation layers from core networking logic, empowering citizens to design, customize, and publish skins, icons, and layouts within a user-generated content cycle.
* **Cross-Platform 3D Bridge (`VOD Entry Standard`):** Orchestrates seamless state handoffs between React/Next.js clients, **Go** microservices, and dedicated **Unity** game servers via **gRPC**, ephemeral 60-second security tickets, and persistent **WebSocket** channels.

### 2. [3D RGB (3DMeta-Shop)](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc%2F3DMeta-Shop-Object-3D) — 3D Asset Marketplace

A dedicated marketplace platform for trading, previewing, and distributing 3D digital objects and `GLTF` spatial assets across the MetaRang virtual economy.

### 3. [Paradise Supply Chain SSO](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc%2FSSO-Paradise-Supply-Chain-Go) — Unified Identity & Access Management

Centralized Single Sign-On (`SSO`) and citizen authentication (`hm-` Citizen IDs) engineered in **Go** and **TypeScript**, securing cross-platform sessions, role-based permissions, and cryptographic identity verification across all holding services.

### 4. [Decentralized Governance \& Web3 (PSC / PSD)](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc%2FMetaverse-Rang-PSC-Governance-Coin)

Smart contract infrastructure developed with **Solidity** and **Foundry**, powering decentralized governance tokens (`PSC`), virtual land transactions, and transparent on-chain economic policies.

## System Architecture & Technical Highlights

### Distributed Microservices & Monolith-to-Go Migration

To support real-time spatial interactions and high-throughput transactions across **[MetaRang](https://www.google.com/search?q=https%3A%2F%2Fmetarang.com)**, our engineering team transitioned the core platform from a legacy Laravel monolith ([Metaverse-Rang-Microservice-Api-laravel](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc%2FMetaverse-Rang-Microservice-Api-laravel)) to a distributed **Go** microservices architecture ([Metaverse-Rang-Microservice](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Firanpsc%2FMetaverse-Rang-Microservice)):

* **Inter-Service Communication:** Low-latency **gRPC** pipelines and event-driven messaging between authentication, property management (`VOD`), economy, and 3D simulation nodes.
* **Real-Time 3D Synchronization:** Secure **WebSocket** channels and 60-second ephemeral session tokens validating citizen permissions, asset ownership, and wallet balances prior to instantiating **Unity** 3D property environments.

### Database Architecture V3 — Encrypted Citizen Pods

Our third-generation storage layer is engineered to host millions of concurrent citizens in **[MetaRang](https://www.google.com/search?q=https%3A%2F%2Fmetarang.com)** with minimal resource overhead:

* **Distributed MongoDB Clusters:** Replaces isolated per-citizen databases with horizontally sharded collections and logical tenant isolation.
* **Encrypted Citizen Pods:** Enforces strict separation between public profile metadata and cryptographically protected citizen records, paired with automated schema versioning and on-demand data provisioning.
